This is the data and code accompanying the following article:

van Baar JM, Aimable A, Teckchandani TA, et al. Intolerance of uncertainty among US and Canadian young adults attending college
1992-2023: a meta-analysis. JAMA Psychiatry. Published online November 18, 2026. doi:10.1001/jamapsychiatry.2026.3843

To reproduce the results from the paper, download the dataset (Data) and R code files (Code) to a project directory, create a Results folder in the same directory, and run code files 1 through 4 in order. You may need to install additional libraries.
